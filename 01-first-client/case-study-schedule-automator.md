## ลูกค้า/บริบท

สถาบันพัฒนาสมอง (brain-training institute) — self-initiated project ปี 2024 (ยังไม่ใช่งานลูกค้าที่ได้รับค่าจ้าง
แต่เป็นปัญหาจริงที่แก้ให้สถาบันจริงใช้งานจริง)

## ปัญหาก่อนเริ่ม

สถาบันใช้ระบบ ERP เดิมจัดตารางเรียน/จัดห้อง แต่ระบบนั้น**ไม่มี API** เปิดให้เชื่อมต่อ ทำให้ทุกครั้งที่ต้อง
จัดตาราง/สร้างห้องเรียนใหม่ ต้องทำมือทั้งหมด: ดึงข้อมูลจาก ERP มาเรียบเรียงเอง แล้วไปสร้าง Google Classroom
ทีละห้องด้วยมือ

> จัดการต่อรอบ?

## ทางแก้ที่ทำ

เขียนโปรแกรม Python ใช้ Selenium **reverse-engineer ระบบ ERP เดิม** (ไม่ต้องรอ vendor เปิด API ให้) ดึงข้อมูล
ตารางเรียน/รายชื่อนักเรียนออกมาอัตโนมัติ แปลงและซิงก์เข้า Google Sheet พร้อมหน้า **Preview ก่อนรันจริง**
(กันความผิดพลาดก่อนกระทบข้อมูลจริง) แล้วต่อ Google Classroom API ให้สร้างห้องเรียนที่ตรงกันอัตโนมัติ มีแดชบอร์ด
สรุปสถานะและระบบล็อคกันรันซ้ำ

## ผลลัพธ์

- ลดงานจัดตาราง/สร้างห้องเรียนจาก **งานที่ต้องทำมือหลายชั่วโมง** เหลือ **ไม่กี่คลิก**
- มีหน้า Preview ตรวจสอบก่อนรันจริง ลดความเสี่ยงข้อมูลผิดพลาดเข้าระบบจริง
- ทำได้กับระบบที่**ไม่มี API ทางการ** — ไม่ต้องรอ vendor ของลูกค้าเปิดให้

> 🟡 **ใส่ตัวเลขจริงถ้ามี:** ลดเวลาลงเหลือกี่นาที/ครั้ง? ใช้งานจริงมาแล้วกี่เทอม/กี่รอบ?

## เครื่องมือ/เทคนิคที่ใช้

Python, Selenium, ChromeDriver, Google Classroom API, Google Sheets

## ใช้กับธุรกิจแบบไหนได้อีก

ธุรกิจ/องค์กรที่มี **ระบบเดิม (ERP/ระบบจัดการ) ที่ไม่มี API** แต่ต้องทำงานซ้ำๆ ทุกสัปดาห์/ทุกเทอม เช่น:

- โรงเรียน/สถาบันกวดวิชา/สถาบันสอนพิเศษอื่นๆ ที่จัดตารางเรียนด้วยระบบเดิม
- คลินิก/ร้านที่มีระบบจองคิวเดิมแต่ต้องโอนข้อมูลไปทำรายงาน/นัดหมายต่อด้วยมือ
- ธุรกิจที่ใช้ระบบ legacy ที่ไม่มีใครดูแล/อัปเดต API ให้แล้ว แต่เลิกใช้ระบบเดิมทั้งระบบไม่ได้
