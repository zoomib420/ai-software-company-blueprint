# 10 — AI Company

> ⚪ วิสัยทัศน์ระยะยาว ไม่ใช่งานตอนนี้ — รอจนกว่า [09-saas](../09-saas/) จะมี recurring revenue ที่ยืนยันแล้ว
> ดู [DECISIONS.md](../DECISIONS.md) ADR-0002

## เป้าหมาย

ตั้ง AI Software Company จริง — ทีมงาน (คน + AI agent) ที่รับและส่งมอบงาน Web App / CRM / ERP / Automation /
AI Workflow / SaaS ได้พร้อมกันหลายโปรเจกต์ โดยไม่ต้องทำทุกอย่างด้วยตัวคนเดียวเหมือน stage ก่อนหน้า

## สิ่งที่ต้องเรียน

- พื้นฐานการจ้าง/outsource งาน (freelancer ไทย/ต่างประเทศ) สำหรับงานที่ทำซ้ำได้ตาม pattern ที่วางไว้แล้ว
- การออกแบบ service catalog ที่ทีมอื่นนำไปทำตามได้โดยไม่ต้องมีเราคุมทุกขั้นตอน
- การออกแบบ agent workflow ภายใน (ใช้ AI agent ช่วย QA, ช่วยเขียน proposal, ช่วย onboarding ลูกค้า) เพื่อขยาย
  throughput โดยไม่เพิ่มต้นทุนคนเป็นเส้นตรง
- พื้นฐานกฎหมาย/บัญชีสำหรับการจดทะเบียนธุรกิจในไทย (นิติบุคคล, ภาษี, สัญญาจ้างงาน)
- การบริหารทีมระยะแรก (1–3 คนแรกที่จ้าง)

## โปรเจกต์ที่ต้องทำ

1. เขียน service catalog จากบริการที่พิสูจน์แล้วทั้งหมดใน stage 01–09 ให้เป็นเอกสารที่คนอื่นอ่านแล้วทำตามได้
2. วาง agent workflow ภายใน (ใช้ repo นี้ + AI agent เป็นระบบปฏิบัติการของทีม)
3. จดทะเบียนนิติบุคคลเมื่อรายได้สม่ำเสมอเพียงพอ

## Checklist

- [ ] SaaS ([09-saas](../09-saas/)) มี recurring revenue สม่ำเสมออย่างน้อย 3 เดือนติดต่อกัน
- [ ] มี service catalog ที่เป็นเอกสาร ไม่ใช่แค่ในหัว
- [ ] จ้าง/outsource คนแรกสำเร็จ และงานที่ส่งมอบผ่านมาตรฐานคุณภาพเดียวกับที่ทำเอง
- [ ] วาง agent workflow ภายในที่ลดเวลาทำงานซ้ำของทีมได้จริง (วัดผลได้)
- [ ] จดทะเบียนนิติบุคคล (เมื่อถึงเวลาที่เหมาะสมตามรายได้จริง)

## งานที่สามารถรับได้ตอนนี้

ไม่มี — stage นี้คือปลายทาง ไม่ใช่จุดเริ่มงาน ดู [01-first-client](../01-first-client/) สำหรับงานที่รับได้จริง
ตอนนี้

## สิ่งที่ยังไม่ต้องทำ

- ❌ ทุกอย่างใน stage นี้ — จนกว่าเงื่อนไขใน Checklist ข้อแรก (recurring revenue สม่ำเสมอ) จะสำเร็จ
- ❌ จดทะเบียนบริษัทก่อนมีรายได้สม่ำเสมอพอจะรองรับต้นทุนคงที่ของนิติบุคคล
- ❌ จ้างทีมใหญ่ตั้งแต่แรก — เริ่มจาก 1 คนที่ outsource งานซ้ำที่สุดก่อน
