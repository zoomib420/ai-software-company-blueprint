# เทมเพลต: Client Proposal / Outreach

> ใช้สำหรับส่งข้อความแรกหรือ proposal ให้ lead — ปรับทุกช่องให้เจาะจงรายนั้นจริง ห้าม copy-paste เหมือนกันทุกคน

## ข้อความ Outreach แรก (สั้น ส่งทาง LINE/อีเมล/DM)

```
สวัสดีครับ [ชื่อ] — ผมซูม สร้างระบบ [ระบุปัญหาที่เห็นจากธุรกิจเขา เช่น "ตารางเรียน/ตารางจอง"]
ให้ [ชื่อธุรกิจ/ประเภทธุรกิจที่คล้ายกัน] ลดเวลาทำงานจาก [X ชั่วโมง/สัปดาห์] เหลือ [Y นาที]
ด้วยระบบอัตโนมัติที่เชื่อมกับ [ระบบที่เขาใช้อยู่แล้ว]

ถ้า [ปัญหานี้] เป็นเรื่องที่ [ชื่อธุรกิจ] เจออยู่ ขอเวลา 15 นาทีคุยได้ไหมครับ
ดูตัวอย่างงานจริงได้ที่ [ลิงก์ case study/portfolio]
```

## โครง Proposal เต็ม (เมื่อเขาสนใจแล้ว)

1. **สรุปปัญหาที่เขาเล่าให้ฟัง** (พิสูจน์ว่าฟังจริง ไม่ได้ส่ง template เดียวกันให้ทุกคน)
2. **ทางแก้ที่เสนอ** — อธิบายเป็นผลลัพธ์ ("ลดเวลา X" "ลดของหาย/ตกหล่น Y") ไม่ใช่ tech stack
3. **ขอบเขตงาน (scope)** — ระบุชัดว่าทำอะไร ไม่ทำอะไร กันสโคปบวม
4. **ราคา + แพ็กเกจ** — ราคาตายตัวถ้าเป็นไปได้ ระบุว่ารวม/ไม่รวมอะไร
5. **Timeline** — วันเริ่ม วันส่งมอบ
6. **วิธีจ่ายเงิน** — มัดจำกี่ % จ่ายเมื่อไหร่
7. **ตัวอย่างผลงาน** — ลิงก์ case study ที่ตรงกับปัญหาเขาที่สุด

## Checklist ก่อนส่ง

- [ ] เจาะจงชื่อ/ปัญหาของ lead รายนี้จริง ไม่ใช่ template ทั่วไป
- [ ] มีลิงก์/ไฟล์ case study ที่ตรงกับปัญหาที่สุดแนบไปด้วย
- [ ] ระบุ scope ชัดพอที่จะไม่ตีความผิดได้
- [ ] ราคาและ timeline ชัดเจน ไม่ใช่ "ติดต่อสอบถาม"
